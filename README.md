# 右脳カチカチ！

マウスでクリックするだけの右脳チェック＆トレーニングゲーム（一人用・オフライン）。
2000年のタッチパネル式アーケードゲーム（脳ゲーの元祖）を参考に、ルールを再構成した自作品です。
名称・画像・音はすべてオリジナルで、元作品の素材は使っていません。

## 遊び方
1. `index.html` をブラウザ（Chrome / Safari / Edge）で開く。サーバー不要。
2. 「右脳能力チェック」: 6種から4ステージが出題され、正しさとスピードで採点。SSS〜Eの16段階ランク、右脳偏差値、自分の過去プレイ内での順位を表示。
3. 「トコトントレーニング」: 好きな1ゲームをライフ3でエンドレス。レベル6でハードコース、11でスーパーハード。ゲームごとにトップ10ランキング。
4. 記録はブラウザの localStorage にのみ保存（外部送信なし）。

## 収録ゲーム
| ゲーム | 分類 | 内容 |
|---|---|---|
| カウントマニア | 集中力 | 1から順に数字ボールをクリック。トレーニングは持ち時間270秒の通し、スキップ2回で配置を変更 |
| カードみくらべ | 判断力 | 上下2列で1枚だけ違うカードを探す |
| カタチさがし | 分析・推理力 | 見本（レベル2以降は回転あり）と同じ形のピースを探す。トレーニングは持ち時間120秒の通し |
| ギュンとナンバー | 反射・直感力 | 一瞬だけ表示される数字を入力。10段階（3桁0.45秒→6桁0.12秒） |
| そっくり文字 | 集中力 | そっくりな文字の中から見本と同じ文字を全部クリック |
| 白タイルきおく | 記憶力 | 白く光ったタイルの位置を覚えてクリック |
| どっちが多い | 判断力 | 左右の枠で動き回るボールの数を比べ、多い側をクリック。10段階（4〜6個・差2→20個前後・差1）。Lv1〜3は静止、Lv4から動く。大きさはLv1〜8は同じ、Lv9から大小混在。回答時間はLv10まで7秒、Lv11から1秒ずつ減り最短2秒 |

## 構成
- `index.html` 1ファイル（HTML/CSS/JS、外部依存なし）。
- 音は WebAudio の簡易シンセ。タイトル画面でON/OFF可。
